# 开发与内容维护

## 当前网页

入口为 `dist/index.html`，主体页面使用 `dist/institute.js` 和 `dist/institute.css`。以入口实际加载的文件判断当前实现；部分未加载脚本和旧样式保留作参考，删除前应检查动态引用。

这是静态项目，根目录没有 npm 安装或整站构建流程。`dist/` 必须保留版本管理，其中包含手工维护的网页、数据、插画和可部署文件。

## 文章修订

`humanizer/revised/<文章ID>.json` 为逐篇修订稿，可编辑 `title`、`subtitle`、`lead`、`chapters`。篇名修订自 2026-11-09 起由 `title` 字段覆盖展示标题；旧稿缺少此字段时沿用原题。保留文章 `id`、馆藏归属和来源笔记名。`humanizer/baseline-articles.json` 是原文基线，`humanizer/round2/current-before.json` 是第二轮开始时的全文快照，供审校对照。

安装 Node.js 后，在仓库根目录运行：

```sh
node build-humanized.cjs
```

它会校验文章结构并更新 `dist/humanized-articles.js` 与 `humanizer/revision-report.json`。提交正文变更时一并提交生成结果。直接修改生成的正文文件会在再次生成时被覆盖。

其他 `build-*`、`prepare-humanizer.cjs`、`complete-editorial-history.py` 等脚本用途不同；部分是已执行的一次性迁移工具。运行前阅读脚本和相关编辑记录，不要依次盲跑所有工具。

## 展室与插画

展室数据位于 `dist/exhibit-data.js`、`dist/travel-data.js`、`dist/street-data.js`，专题说明见 [FIELDROOMS](专题/FIELDROOMS.md)。

当前器物主图使用静态插画。绘图工具及先前三维实现的记录见 [绘图说明](../tools/drawing/README.md)，器物开发工具依赖仅在需要重新绘图时恢复；普通预览无需安装这些工具。

移动网站文件时同步检查 CSS、脚本、素材与动态加载路径。移动文章源数据或根目录生成脚本时，先检查其相对路径约定。
