# 仓库维护

## 目录约定

`dist/` 保存网站文件及必要素材；`humanizer/` 保存文章修订源与审校记录；`docs/` 按设计、编辑、专题与历史归档说明；`tools/` 保存开发辅助工具。

根目录生成脚本与编辑 JSON 保留原路径，以保持其文件读取约定。新增长期维护的工具优先放入 `tools/`，并提供用法与所需环境说明。

## 跟踪与忽略

保留跟踪网页、文章、图片、第三方许可原文、共享设计规范和 Sites 配置。忽略依赖安装目录、Python 环境、缓存、操作系统杂项、编辑器本机状态、临时文件、压缩导出包和凭据。

不要用通用前端模板忽略 `dist/`，也不要整体忽略 `.openai/`。本项目的部署配置可以共享，临时凭据、运行日志和本机状态需要排除。

`.gitignore` 不会删除历史提交中的文件。导出文件如需保存，放在本机 `exports/` 或仓库外；不要提交重复压缩包。

## 提交前

检查修改是否限于本次任务、页面引用是否有效、正文源稿与生成结果是否对应，以及是否意外加入本机路径配置或账户凭据。文档或结构调整不需要重新生成正文。
