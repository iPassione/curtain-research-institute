# 跨设备同步与发布

## 首次克隆

```sh
git clone https://github.com/iPassione/curtain-research-institute.git
cd curtain-research-institute
```

公开仓库可直接克隆；推送修改需要有写入权限的 GitHub 账号。

每次编辑前先在无未保存改动的工作区拉取：

```sh
git pull --ff-only
```

完成编辑后检查并提交：

```sh
git status
git add -A
git commit -m "说明本次修改"
git push
```

分支分歧或同文件冲突应先检查并合并，避免强制覆盖另一台机器的修改。跨设备继续世界设定创作时，可另外克隆 [知识库](https://github.com/iPassione/curtain-obsidian-vault)，两个仓库各自维护。

## 发布网站

GitHub 推送保存项目源码，不会自动部署网站。Sites 项目身份与静态目录由 `.openai/hosting.json` 声明；继续发布时使用此现有项目，保留原有访问方式与站点地址。

发布凭据由 Sites 临时提供，不应写入仓库、命令历史或项目文档。`.openai/hosting.json` 只有项目标识与静态目录，属于可共享配置，应继续跟踪。

历史交接记录与恢复点见 [原交接文档](历史/2026-11-03至05-交接记录.md)，其中版本号及分支状态仅代表记录时点，当前发布版本需查看 Sites 状态。
