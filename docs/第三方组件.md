# 第三方组件

《帷幕》的原创文字与美术、项目代码及第三方组件的权利应分别理解。本仓库未为原创内容指定统一开源许可证，第三方文件保留其原有版权和许可声明。

- 页面使用 [Google Fonts](https://fonts.google.com/) 的 Noto Serif SC 和 Noto Sans SC。
- 页面通过 CDN 使用 [GSAP](https://gsap.com/) 及 ScrollTrigger。
- `dist/vendor/` 中保留浏览器依赖和许可文件；部分组件来自过往实现，是否生效以页面实际加载为准。
- 器物图版工具涉及 Three.js、Maker.js、Rough.js 与 Zdog，来源和恢复说明见 [绘图工具](../tools/drawing/README.md)，许可原文见 `dist/vendor/licenses/` 与对应组件目录。

再次分发第三方依赖时，应保留其许可声明并遵循对应来源的条件。本页不替代上游许可证。
