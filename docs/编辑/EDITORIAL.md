# 帷幕研究所正文写作规范

用户授权：可以增添与核心设定相容的文化、日常生活、行业惯例、程序细节；不以资料较少为由反复写研究空白。新增细节留在网站与本文件旁的增补记录，不写回原始知识库。不得新增颠覆核心历史、人物结局、秘密身份的事实。重大剧情仍不公开。

## 正文要求

- 模仿用户《离散纪》《十九家》的内部史学口吻。必须重新写完整正文，不拼贴旧段落。
- 一篇有一个中心问题和发展脉络。一般正文 1800–3200 汉字，重点地方志 2500–4500；长度仅是防止摘要冒充正文的下限，不能用套话填充。
- 4–7 个章节，每章约 300–650 字，2–4 个自然段。自然段通常 90–220 字，允许节奏变化。
- 每个章节要交代具体过程、实际后果、例子或历史关系，不能在标题下仅复述结论。
- 写明人怎样办事、知识怎样传递、成本由谁承担、制度怎样执行、不同立场为何冲突。允许自洽的细节创造，但不得发明假参考文献和假引语作证。
- 禁止反复出现“现有资料不足”“不能简单概括”“为理解提供入口”“值得观察”等充篇幅句子。禁止结尾用泛泛的写作方法论代替内容。
- 对一个城市可以写从业者、公共办事、工坊、街区生活等合理细节，但不擅自给未定的十九家命名或增添重大历史事件。
- 人物以已知经历展开，加入有根据的行为分析和生活场景细化；不编造人物重大行动、台词或未来结局。
- source 保留真实笔记名。additions 在后台增补记录中说明哪些细节为创作延伸，不在产品正文显示实现说明。

## 交付格式

每组交付 JSON 数组：[{id,title?,subtitle?,lead,chapters:[{heading,paragraphs:[...] }],source:[...],additions:[...]}]。只覆盖授权 id 的正文。不要改其他脚本或知识库。保留原文两篇不改。
