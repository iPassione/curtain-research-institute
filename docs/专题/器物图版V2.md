# 器物结构图版 V2：现代短杖、封咒蕴法石、界门

写于 2026-11-18。造物陈列室「结构图版」视图里的三张图版，按知识库设定做结构细化后重绘。生成脚本 `tools/drawing/plates-v2.mjs`，产物写入 `assets-src/plates/`（`wand.svg`、`stone.svg`、`gate.svg`）。

## 原则

- **只画设定里写明的东西**：每一处标注都能在下面的「依据」里找到出处。设定没写的，不补机制、不标尺寸、不编号。
- **不改展品文字**：展品的名称、提要、事实栏与两章正文保持原样；图版是插画的补充读法。
- **不涉剧透**：三件器物与主线人物、隐藏身份无关；图版里不出现人物，长杖与短杖的对比也不提具体人物。
- **形制约束沿用**：短杖与长杖纯木质，不镶宝石，不用金属箍或皮革包覆（见 `tools/drawing/README.md`）。
- **版式**：900×1125（4:5，与插画同比例，切换时不跳动）。左侧是主视图，右侧四条细节注释，页眉与页脚沿用旧图版的研究所档案格式。

## 没有画的

- 魔杖的木材品种、杖芯：设定没有写，旧图版也没有。
- 蕴法石的具体容量数字、咒语等级与石头大小的对照：设定明确说两者无关，图上只画相对关系。
- 界门的传送原理、能量来源、编号、具体城市：设定没有写，或属于不公开的管理信息。
- 「用过的蕴法石」（04）这次没有重绘，它的流向已画进蕴法石图版的注释 4；要统一画风可以另做。
