# Design System: 帷幕研究所

## Overview

**Creative North Star: "夜间开放的研究图志"**

研究所的前端以深绿书封和浅色书页组织不同阅读场景。穹顶观测图、航海图和研究桌是实际使用的图像资产；器物感来自图像、细边线与方正版面，而不是在正文后叠加纹理。

首页属于 Experience：主视觉先建立世界感，研究方向和选读把访客带入馆藏。正文属于 Read：暖白背景、衬线长文和独立索引让阅读成为主任务。历史、地理、魔法、人物、诸界、日常、阅览室七个馆藏共用同一图志体系，已有地图与专题工具保持各自完整的交互。

**Key Characteristics:**

- 深色导览与浅色正文形成清楚的场景切换。
- 中文衬线字体承载标题和正文，无衬线字体承载导航与控制。
- 文章条目采用开放式分隔线，主方向入口采用书封式色块。
- 铜金色用于索引、选中和行动提示。

## Colors

YAML frontmatter 是规范值；七个全局 CSS 变量与同名颜色一一对应。

- 书封绿 `green`：馆藏页头、方向入口和交互说明面板。
- 夜间深绿 `deep`：全局页头、页脚、首页背景与研究桌区域。
- 暖白书页 `paper`：正文、文章列表和通用内容区域。
- 墨绿 `ink`：浅底上的标题、正文与表单值。
- 草灰绿 `muted`：摘要和辅助说明。
- 铜金 `brass`：设计系统的索引角色；实际组件存在局部铜金色阶，新增内容优先复用已有角色。
- 纸页分隔色 `rule`：文章条目、提要和目录分隔。
- 主行动和键盘焦点使用 frontmatter 的专用角色。

方向入口已有土棕、蓝灰和橄榄绿色面，分别服务人物、诸界与日常。专题图中的羊皮纸和金属色由专项 CSS 管理，不强制替换为普通页面色值。

## Typography

标题与长文使用 Noto Serif SC，回退至 Songti SC 和 serif；界面使用 Noto Sans SC，回退至 Microsoft YaHei 和 sans-serif。少量篇章编号使用 Georgia。

首页显示标题采用 display token。文章标题在桌面采用 `clamp(36px, 4.5vw, 64px)`，手机缩至 34px；馆藏标题采用 `clamp(37px, 4.5vw, 64px)`。正文小节标题采用 heading token，手机为 25px。

正文默认 reading token，用户可在 16–24px 间调节并保存偏好；手机行高改为 2.05，字距归零，左对齐。桌面正文两端对齐。内容提要 20px，手机 18px。导航、阅读时长和条目标签使用界面字体，通常为 10–13px；英文标签只承担辅助索引。

## Layout

全站先采用正常文档流页头，不固定遮挡内容。桌面页头高 88px，窄屏为 76px。通用馆藏容器最大 1200px；首页导览区域最大 1440px，首页方向入口和选读区域最大 1240px。

首页方向入口桌面三列、850px 以下两列、550px 以下单列。手机入口自身变成插图在左、文字在右的横向书封。研究桌区域桌面图文两列，850px 以下变为上下排列。

文章采用 210px 篇章索引、70px 间隔和最大 750px 正文。1150px 以下索引收窄；850px 以下目录回到正文前并自动换行。手机表单与文章列表改成单列。馆藏页头的装饰图在 550px 以下隐藏，标题、介绍和浏览入口保留。

## Elevation & Depth

页面主要靠色面、细边线、图像和空白形成层次。普通文章条目没有浮起阴影。手机展开菜单使用向下的柔和阴影（`0 15px 25px #0c282430`）。地图转盘的边缘、金属环和阴影来自保留的 `nautical-map.css`，属于仪器本身。

## Shapes

主要控制与版面使用直角，1px 细边线是常见分隔方式。圆形用于观测、魔法与转动地图等特定主题。大陆点位是菱形，悬停或键盘聚焦才显示标签；方位标签不作为常驻贴纸铺在图上。

## Components

### Navigation

页头使用深色底与浅色文字；当前馆藏用金色文字及下划线识别。850px 以下显示“目录”按钮，展开后为两列链接，支持 Escape 关闭及点击页头外关闭。跳至正文链接仅在键盘聚焦时显示。

### Actions and Fields

主行动采用浅金底、深绿字和直角；次级动作采用文字下划线。全局键盘焦点为 2px 铜金描边，向外偏移 5px。搜索与筛选使用透明底和底部边线；输入值为 16px。

### Collection Entries

首页六个方向均使用独立横幅封面：地理沿用航海图，人物保留匿名群像，其余四馆采用欧洲现实主义油画。画面以人物与场景关系、油彩笔触、统一色调和自然光组织，不使用童话插画、密集颗粒或摄影感替代油画。魔法图展示多支现代短杖、研究记录与测量工具；历史图必须保有清楚可信的陆地和水域关系。各馆页头复用对应图像。人物群像不对应已命名角色的正式外貌。桌面封面高 210px 并裁切至中心；550px 以下改为完整宽度的 16:9 横幅，与标题说明上下排列。

文章条目用细线分隔，包含主题、阅读时长、标题、摘要和阅读动作。标题悬停变为铜棕色；条目底部动作保留充分间隔。公共阅览室同时按全文关键词与研究领域筛选，显示结果数量和空结果提示。

### Reading Folio

文章顶部依次为返回链接、类别、标题、副标题和阅读元信息。桌面左侧目录随滚动停留，当前章节以铜金底边强调。提要与正文分隔；每章有编号、标题与完整段落。字号按钮始终限制在支持范围，页面顶部细进度条反映正文阅读进度。文末以菱形、资料来源和关联文章收束。

### Working Exhibits

`visual-atlas.css`、`nautical-map.css`、`collections.css` 先载入，`institute.css` 最后载入并协调颜色、字体与间距。保留地图转动与点选、施法分阶段演示、人物关系、诸界观测、生活专题和货币换算，避免重写系统样式时覆盖其定位与状态逻辑。

首页 GSAP 仅编排一次标题组进入与主视觉滚动位移；CSS 悬停过渡通常为 0.2–0.25 秒。减弱动态偏好下取消 CSS 动画、过渡和平滑滚动，并跳过首页 GSAP。内容默认可见，第三方动画加载失败不会隐藏内容。

## 穹顶之下：夜色外壳（2026-11-10）

`dist/veil.css` 最后载入，接管全站页头、页脚、首页，以及馆藏和文章页头。正文、馆藏目录、地图和专题工具仍使用书页色面，不受影响。

- **色值**：夜 `#07110f`、夜二 `#0b1916`、夜三 `#11241f`；帷光 `#f1e2b4`、铜金 `#d4b36e`、暗金 `#a98b55`；月白 `#f4eedc` 用于深底标题，雾灰 `#c9d3c8` / `#97a69b` 用于深底正文和辅助文字。金色细线为 `#d4b36e2e`。
- **穹顶弧线**：全站共用的标志元素。首页主视觉有三层弧线：外弧、带模糊的光晕弧和主弧，载入时由 3.4 秒的 expo 缓动画出；一道光点沿主弧缓慢巡行，周期 16 秒。馆藏页头和文章页头使用单层弧线；页脚有双弧。首页主视觉与导览之间用一条带菱形节点的浅弧分隔。弧线默认可见，减弱动态时取消绘制动画并隐藏光点。
- **品牌标记**：穹顶罩着地平线，内有一颗四芒星，取代原先的 ✳。
- **拉丁字体**：Cormorant Garamond 斜体，只用于英文馆藏名、首页时间标注和馆藏页头的 kicker，中文字体角色不变。
- **首页**：页头透明，叠在主视觉之上；主视觉占满一屏。六个馆藏入口改为整幅油画窗格：桌面端按 7/5、5/7、7/5 交错排列，850px 以下两列，550px 以下单列。窗格有内框，悬停时内框内收并变亮，画面缓慢放大；标题叠在画面底部，压在按馆藏染色的渐层上。
- **页脚**：双层穹顶弧，中间是居中的大字格言，下面一行放品牌、馆藏导航和返回顶部。

## 阶段 1：阅读体验与全站外壳（2026-11-17）

新增样式放在 `src/styles/read.css` 的 `v3` 层，晚于既有的 `site` 层。颜色只用已有角色，没有新增色值。

- **中文排印**：正文与提要启用 `text-spacing-trim: trim-start`、`text-autospace`、`hanging-punctuation`、`text-wrap: pretty`、`line-break: strict`；标题用 `text-wrap: balance`。效果是段末不再只剩一两个字，中文与数字、拉丁字母之间留出细空。章节编号改用旧式数字，并在支持滚动驱动动画的浏览器里随滚动轻移 14px。不支持的浏览器排版与之前相同。
- **术语批注**：词条为虚线下划线（铜金 65% 透明），悬停或聚焦变铜棕。摘要卡用书页底、细边框、2px 铜金顶边，宽 320px，类别、术语、五行以内的提要和「阅读」链接自上而下排列。触屏第一次轻触展开卡片，再点链接进入文章。
- **继续阅读**：底部居中的夜色条，左侧写上次读到的章节，右侧浅金主行动「从上次读到的地方继续」和关闭按钮。跳转后目标段落短暂铺一层铜金底色。窄屏下改为左右贴边的整宽条。
- **检索**：页头按钮在宽屏显示文字与快捷键，850px 以下只留放大镜，排在「目录」按钮左侧。面板为书页底，结果分为馆藏、文章、章节、展室四类，选中项铜金左边线，命中词以浅铜金底标出。
- **转场**：站内切换时页面交叉淡化 0.22 秒；从目录条目进入文章（或返回）时，条目标题与文章大标题以 0.5 秒 expo 曲线互相变形。减弱动态或浏览器不支持 View Transitions 时直接切换。

## 阶段 2：首页「穿过帷幕」（2026-11-17）

支持 WebGL2、且未要求减弱动态、未开省流模式时，首页主视觉换成约五屏滚动距离的固定舞台；否则保留上面描述的原首页。代码在 `src/gl/`，样式在 `src/styles/journey.css`。

- **四幕**（滚动进度）：一 外海（0–0.2）夜海、星空、远处一点船灯；二 显形（0.2–0.45）薄膜从边缘反光开始浮现，SVG 弧线淡出；三 穿幕（0.45–0.7）滑动变焦推近，贴着薄膜慢慢穿过（约占 9% 的滚动距离），进入后视角撑开；四 穹顶之下（0.7–1）镜头升起俯瞰海面上的五大陆航海图，最后画面暗下，交给馆藏入口。
- **设定依据**：帷幕透明、柔软、自带支撑；没有魔力的凡人看不见内部，所以从外面看时薄膜只折射外面的海与天，航海图只在镜头进入穹顶后显现；内部比外面估算的更大，所以穿过时视角撑开。
- **薄膜**：菲涅尔边缘光；薄膜干涉色只在铜金 `#d4b36e` 与青绿 `#5d9f94` 之间；经纬织纹在远处是 1 像素细线，贴近时按格子比例放大（上限约 5 像素）并带柔光；进入穹顶后织纹成为头顶的天幕。分远近两层绘制，近侧在完整档带折射。
- **颜色**：夜空 `#01070a`→地平线 `#123430`，海 `#03100e`，月光 `#f4eedc`，帷光 `#f1e2b4`。泛光只让月亮、金色边缘过阈值。
- **文案**：全部沿用原首页的句子。标题组在第一幕；「公元 1077 年……」两句在第二幕居中，只在标点处断行；第四幕「开放馆藏 / 选择你的研究方向。」与下方标题重复，对读屏隐藏。五大陆地名取自现有大陆数据，位置与地理馆航海图一致，同样对读屏隐藏。
- **档位**：完整（2 倍像素比上限、折射、泛光）、精简（1 倍、无折射、无泛光、粒子减半）、静态（原首页）。连续 2 秒低于 45 帧自动降一档，并在本次会话内保持。

与施工方案的出入：后期合成用 three.js 自带的 EffectComposer 与 UnrealBloomPass，没有另装 `postprocessing`；没有引入 Lenis 平滑滚动；性能分档用设备特征加实测帧率，没有用 `detect-gpu`；第四幕没有把六个馆藏名放到大陆上（馆藏与大陆没有对应关系），改为标注五大陆本身。

## 阶段 3：地理馆立体航海图（2026-11-17）

支持 WebGL2、有显卡加速、未要求减弱动态时，航海图室的转盘换成三维浮雕；否则保留原转盘。代码在 `src/gl/chart-room.ts`、`src/gl/scenes/chart.ts`，样式在 `src/styles/chart.css`。

- **浮雕**：`scripts/derive-height.mjs` 从航海图离线派生高度图（`assets-src/data/nautical-height.png`）：陆地纹理密、海面纹理稀，用局部亮度方差分出陆地，模糊成柔和的海岸坡度，再叠上山地纹理。最高处约为图宽的 3%，只求「羊皮纸上隆起」，不做真实地形。
- **画面**：西北偏高处的暖色侧光，背光面略偏冷；纸纹；海面上缓慢流动、断续的墨线；低频云影掠过；铜色木边与桌面上随光偏移的柔和投影；完整档的画面上下边缘轻微虚化（移轴）。
- **交互不变**：旋转按钮、复位、滑杆、缓慢转动、拖动与键盘都沿用原实现；三维只读这份状态。五个大陆按钮仍是原来的按钮，移到画布之上的叠层，每帧放到浮雕上对应的位置；跑出画面的按钮只淡出、仍可用键盘聚焦，聚焦时贴着画面边缘显示。新增：鼠标纵向拖动调俯仰（触屏纵向仍用于滚动页面），松手时带惯性。
- **点选**：镜头飞近选中的大陆并更陡地俯看，其余陆地压暗、海面略暗；悬停的大陆轻微提亮。复位朝北回到总览。
- **界门弧线**：魔法联合部总部在中央大陆的普诺伊瓦，各大陆分部经界门与总部往来（见馆藏《界门与距离》），所以只画中央大陆与其余四块之间的四条金色弧线，一道光沿弧线缓缓流过；悬停或选中相关大陆时变亮。图下说明写明「示意往来，不表示航线与距离」。
- **软件渲染**：没有显卡加速时（虚拟机、远程桌面、显卡被禁用），浏览器用 CPU 模拟 WebGL，首页与航海图都直接使用静态版本。

未做：施工方案中「从首页进入地理馆的镜头连续」。两个页面的结构与镜头完全不同，硬接会让首页第四幕被迫迁就地理馆的构图，暂不实现。

## 阶段 4：魔法研究室「施法台」（2026-11-17）

支持 WebGL2、有显卡加速、能在 GPU 上做浮点纹理计算、未要求减弱动态时，「一次咒语的形成」图解上叠加可亲手施法的粒子装置；否则保留原 SVG 图解。代码在 `src/gl/casting-room.ts`、`src/gl/scenes/casting.ts`，样式在 `src/styles/casting.css`。

- **依据**：《施法原理详论》的四个阶段；「火焰需要高活性，冰霜需要低活性，防御则追求稳定」；「结构不稳时，力量可能在释放之前反噬」。没有新增设定，也没有使用公开馆藏之外的句子。
- **操作**：按住台面或「按住施法」按钮（键盘按住空格／回车）。起势约 1.1 秒，粒子沿「∞」回路流动；塑形约 1.3 秒，聚成所选结构；稳定约 2.6 秒，扰动收敛，稳定阶段的说明「咒文稳定并进一步雕琢已经成形的魔力……」随稳定度逐字点亮。稳定后松手，力量朝指针方向导出（键盘为右上方），撞上台面边缘的弧线散成光尘。提前松手，结构溃散，回到起势。
- **三种结构**：火焰——粒子从底部不断上涌、越高越窄、横向闪动；冰霜——六主枝带侧枝的冰晶，位置吸附到细格点，几乎不动；防御——均匀铺在球壳上，整体缓慢转动。颜色分别为橙到浅金、冰蓝白、铜金。
- **原有部分不变**：四个阶段按钮、下方说明（aria-live）与「演示一次」照常工作；施法过程中阶段按钮自动跟着走，直接点阶段按钮或「演示一次」时粒子展示对应阶段。「概念图解」的说明移到台面左上角。
- **规模**：完整档 256²≈6.5 万个粒子，精简档 128²≈1.6 万；粒子越多单个越暗，避免叠加后过曝。

## 三维舞台的两处修正（2026-11-17）

- **画布偶发停在「加载中」**：视口可见性监听原先只读每批通知的第一条。画布挂上时若还不在视口里、紧接着又滚进视口，两条记录会在同一批送达，舞台就一直以为画布不可见，渲染循环永不启动。现在只看属于当前画布的最后一条。页面加载时快速滚动的真实访客同样会遇到，首页、航海图、施法台、诸界下潜都受影响。
- **自动降档从未生效**：预热帧数原先只在等待就绪时累加，就绪后停在 2，而降档判断要求预热超过 30 帧。现在每帧都累加。另外单帧渲染出错时，记录错误并退回静态版本，不再让循环静默中断。
- 自动化测试环境（`navigator.webdriver`）下，舞台挂在 `window.__curtainStage` 上供诊断；普通访客不会触发。

- 只用时间轴里已有的五个事件，不补事件。事件文字是正常的页面内容。

**人物档案馆「星座图」**
- 原关系图换成一幅星座：夜空、闪烁的远星、两道虚线轨道环；七个人物按钮保持原位，各自下方一颗星。
- 只画已有的关系：庭代尔与骑士团六席之间「导师与追随者」，弧度沿用原图。六席彼此之间没有写关系，所以不画连线，也不暗示身份或亲疏。
- 选中庭代尔时六条线全亮（与原图一致）；选中或悬停某一席时，只有它与庭代尔之间的线亮起，一点光从中心流向它；悬停时弧线中点标出「导师与追随者」。首次进入时六条线依次描出。
- 与施工方案的出入：方案写的是力导向布局。这里只有七个人、一种星形关系，力导向排出来仍是一个中心加六个点，还会打乱原图按席次排列的位置，所以保留原位置。

## 阶段 8：打磨与发布准备（2026-11-18）

不改视觉方向，只修问题、补测试。

- **对比度**：原有配色里十几处说明文字（铜金小标签、灰绿注释、展室目录序号等）略低于 WCAG AA 的 4.5:1，大多在 4.2–4.48，少数在 3.0–3.9。每处只压暗到刚好达标（约 4.6:1），色相不变，集中写在 `src/styles/a11y.css`。文章章节前的大号序号是装饰（`aria-hidden`），保持原样。
- **可读名称**：页头与页脚的研究所标志、检索按钮、正文字号按钮、街景编号的可读名称都包含了画面上看得到的字；检索按钮上的快捷键提示改由样式画出，不再算进按钮名称。
- **检索结果列表**：选项角色从列表项移到链接本身（选项里不能再嵌一个可聚焦的链接），选中项的类别标签加深。键盘、鼠标与读屏的用法不变。
- **布局偏移**：脚本把页面画出来之前，正文区先占满一屏，页脚不再先出现在首屏再被推走。累计布局偏移从 0.55（桌面）、0.34（手机）降到 0。
- **题图预载**：馆藏页题图是 CSS 背景、城市切片街景由脚本插入，浏览器发现得晚。`index.html` 里一段内联脚本按地址提前预载（手机宽度不显示题图，不预载题图）。
- **路由**：新页面还没画出来就按返回时，取消那次切换并还原导航高亮，不再出现「地址是上一页、内容是下一页」。按需载入的增强模块与数据在跳转中被中止时静默放弃，保留原版式。

## Do's and Don'ts

- **Do** 根据已实现的颜色变量和两个字体角色扩展页面。
- **Do** 为长文保留完整内容、清楚目录和有节奏的章节分隔。
- **Do** 同时检查桌面与窄屏，保留搜索、地图与专题工具的状态反馈。
- **Do** 为键盘焦点提供可见样式，并尊重减弱动态偏好。
- **Don't** 在正文背景增加妨碍阅读的装饰纹理。
- **Don't** 把馆藏摘要当作正文的替代物。
- **Don't** 用全局排版调整破坏专项地图和图解的定位。
- **Don't** 依赖动画完成内容显示或基本导航。
