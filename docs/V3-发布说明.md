# 帷幕研究所前端 V3 · 发布说明

写于 2026-11-18。给发布前的最后核对用：这次改了什么、验证到哪一步、发布前还要人工看什么。发布由用户在 Codex 里执行（Sites 项目的静态目录是 `dist/`）。

## 一、这一版有什么

正文、摘要、展室文字与设定数据一字未改；所有地址（含旧文章别名、展室参数）与改版前一致。

| 位置 | 新内容 |
| --- | --- |
| 全站 | 单页切换与标题转场、全站检索（Ctrl K 或 /）、术语批注、记住阅读位置、自托管字体、AVIF/WebP 多尺寸图片 |
| 首页 | 「穿过帷幕」：四幕滚动的三维场景，海面、穹顶、隆起的五大陆 |
| 历史研究室 | 横向滚动的长卷，时间长河作为底纹 |
| 地理与文明馆 | 立体航海图：昼夜、缩放、界门往来 |
| 魔法研究室 | 施法台：四个阶段的粒子演示，三种导出效果 |
| 人物档案室 | 人物星座图 |
| 诸界观测 | 「层积的六界」：随时间长河一路下潜，经过星之世界、中层三界、亡者世界，最后揭晓时间长河 |
| 开放展室 | 城市切片的时间轴（街景连续过渡、入夜亮灯）；街景与藏品插画随指针的深度视差；展品插画与图版之间的溶解转场；旅行案头的航线小图与行装卡片 |

三维场景只在支持 WebGL2、有显卡加速、没有要求「减弱动态效果」、没开省流模式时启用；其余情况下页面与改版前相同。所有按钮、文字和交互在没有三维时照常可用。

## 二、已经验证的

- **测试**：Chromium 上 100 项（含五组三维场景测试）全部通过；Firefox 与 WebKit（Safari 内核）上普通页面的 144 项全部通过。
- **三维场景**：首页、航海图、施法台、诸界下潜在 Chromium、Firefox、WebKit 上都能渲染，无报错。
- **无障碍**：axe-core 按 WCAG 2.1 A/AA 扫描 13 个主要页面与检索面板，全部通过；键盘依次走过各页所有可聚焦元素，都有 2px 铜金色焦点框。
- **性能**（模拟约 10 Mbps 宽带、冷启动；三维场景在测试环境里降为静态，不含帧率）：

| 指标 | 方案要求 | 实测 |
| --- | --- | --- |
| 文章页脚本（压缩后） | ≤ 70 KB | 约 11 KB，不载入三维代码 |
| 文章页最大内容绘制 | ≤ 1.8 秒 | 桌面 1.6–1.7 秒，手机 1.4–1.5 秒 |
| 首页三维代码（压缩后，按需载入） | 约 180 KB | 约 146 KB |
| 累计布局偏移 | < 0.05 | 各页均为 0 |

馆藏页的最大内容绘制是题图：地理馆约 1.9–2.1 秒（航海图 270 KB），其余 1.3–1.8 秒。

## 三、发布前请人工看一眼

这些在本机测试环境里核对不了：

1. **iPhone / iPad 的 Safari**：首页滚动是否顺、施法台的粒子是否正常（用到浮点纹理）、城市切片拖动时间轴、诸界下潜。
2. **安卓手机的 Chrome**：同上，重点看首页与诸界下潜的流畅度。
3. **集成显卡的笔记本**：三维场景是否稳定；掉帧时应自动降档（`?debug=gl` 可在左下角看到档位与帧率）。
4. **线上地址**：发布后打开几篇旧链接（含旧文章 ID）、三间展室带参数的地址，确认与本地一致。
